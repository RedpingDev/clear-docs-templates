# Docs 스타일 가이드

개념·구조·참조 문서를 같은 읽기 방식으로 작성하는 기준입니다.

- **첫 화면:** 제목과 목적, 핵심 2~3개를 먼저 보여줍니다.
- **본문:** 짧은 문단과 가로 구분선으로 구역을 또렷하게 나눕니다.
- **시각 자료:** 이해나 검색을 돕는 도식·표·예시를 필요한 위치에 둡니다.

## 정보 순서

문서 첫머리는 제목, 목적 한 문장, 핵심 요약 2~3개 순서로 작성합니다. 목적은 읽은 뒤 이해하거나 찾을 수 있는 내용을 설명하고, 요약은 실제 결론이나 중요한 조건을 담습니다.

본문의 `##` 구역이 5개 이상이면 요약 다음에 짧은 바로가기 목차를 둡니다. 본문 제목과 목차를 함께 바꾸고, 출처·버전 같은 보조 정보는 요약 뒤에 둡니다.

상세 설명은 기본으로 펼쳐둡니다. 빈 섹션을 억지로 채우지 말고 필요 없는 구역과 해당 목차 항목을 함께 제거합니다.

---

## 제목과 여백

문서 제목은 `#` 하나, 주요 구역은 `##`, 항목별 설명은 `###`로 작성합니다. 제목은 ‘기타’처럼 모호한 표현보다 독자가 찾는 개념이나 작업을 드러냅니다.

요약 영역과 첫 본문 구역 사이, 그리고 주요 `##` 구역 사이에 `---`을 둡니다. `###` 앞에는 반복해서 구분선을 넣지 않습니다.

제목·문단·목록·표·코드·이미지의 앞뒤에 빈 줄을 둡니다. 여러 빈 줄만으로 화면 여백을 늘리려 하지 않고, 반복 `<br>`·공백 이미지·문서 전용 CSS는 사용하지 않습니다.

---

## 문장과 강조

한 문단에는 한 가지 내용을 담고 기본 2~3문장으로 씁니다. 한 문장으로 충분하면 늘리지 않으며, 의미가 바뀌는 지점에서 문단을 나눕니다.

굵은 글씨는 핵심 용어와 결론에 사용합니다. 문장 전체를 반복해서 굵게 처리하거나 장식용 이모지·배지를 붙이지 않습니다.

한국어를 기본으로 사용하고 기술 용어는 처음 등장할 때 풀어 설명합니다. 코드·설정 키·명령어는 원문을 유지합니다.

주의사항은 해당 행동이나 조건 가까이에 일반 문장 또는 **주의:**로 적습니다. 색상이나 전용 알림 문법이 없어도 의미를 이해할 수 있게 합니다.

---

## 표와 코드

표는 비교나 빠른 조회에 사용하며 기본 4열 이내로 유지합니다. 한 셀에 여러 문장을 넣어야 한다면 항목별 설명으로 옮깁니다.

순서가 있는 작업은 번호 목록, 병렬 정보는 글머리 목록으로 작성합니다. 목록은 기본 한 단계로 유지하고, 복잡한 중첩은 하위 제목으로 나눕니다.

코드 블록에 언어를 지정하고 예시 바로 다음에 의미나 예상 결과를 설명합니다. 긴 명령과 경로는 가능한 범위에서 줄을 나누되, 복사했을 때 동작이나 값이 달라지면 안 됩니다.

## 이미지와 원본

구조 문서는 전체 구조도를 포함합니다. 개념 문서는 그림 또는 구체적인 짧은 사례를 사용하고, 참조 문서는 표와 코드 예시만으로 충분하면 이미지를 생략합니다.

PNG와 같은 기본 이름의 `.mmd`를 나란히 보관합니다. 기존 편집 도구로 만든 그림은 해당 원본을 보관하고, 이 묶음의 자동 도식 생성 대상과 구분합니다.

도식은 중립색 배경과 파란 강조색을 기본으로 사용합니다. 캔버스 안에 여백을 두고 불투명한 밝은 배경을 사용해 어두운 화면에서도 글자와 선의 대비를 유지합니다.

그림의 노드가 많아 글자가 작아지면 전체도와 세부도로 나눕니다. 한 화면에 억지로 많은 내용을 넣지 않습니다.

각 그림에는 관계를 설명하는 대체 텍스트와 바로 다음 문단의 한 문장 해석을 제공합니다. 이미지 안에만 있는 필수 정보는 본문에도 적어 검색과 수정이 가능하게 합니다.

## 문서 종류와 연결

| 종류 | 기본 본문 순서 | 읽은 뒤 할 수 있는 일 |
| --- | --- | --- |
| 개념 | 필요한 이유 → 도식·예시 → 원리 → 오해 → 관련 문서 | 개념의 의미와 쓰임 설명 |
| 구조 | 전체도 → 역할 → 흐름 → 의존성·제약 → 관련 문서 | 구성과 연결 관계 파악 |
| 참조 | 항목 색인 → 항목별 설명 → 사용 예시 → 관련 문서 | 필요한 값과 조건 조회 |

관련 문서는 존재하는 파일만 상대 링크로 연결하고, 링크 옆에 읽을 이유를 짧게 적습니다. 참조 표의 항목명에는 해당 `###` 제목으로 이동하는 앵커를 연결합니다.
