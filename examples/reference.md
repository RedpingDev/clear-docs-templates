# 파일 백업 도구 설정 참조

`backup.json`의 필수 설정과 경로 조건을 찾아봅니다.

- **설정 파일:** UTF-8 JSON 형식의 `backup.json`을 사용합니다.
- **필수 항목:** `source`와 `destination`을 모두 지정합니다.
- **경로 조건:** 두 폴더는 같거나 서로 포함하는 관계일 수 없습니다.

이 문서는 [가상 프로젝트의 공통 자료](source-notes.md)를 바탕으로 작성한 양식 예시입니다.

---

## 항목 색인

| 항목 | 의미 | 필수 여부 | 기본값 |
| --- | --- | --- | --- |
| [`source`](#source) | 백업할 원본 폴더 | 필수 | 없음 |
| [`destination`](#destination) | 스냅샷을 보관할 폴더 | 필수 | 없음 |

---

## 항목별 설명

### source

백업할 파일이 들어 있는 원본 폴더입니다. 실행 시 하위 폴더 구조를 유지하며 전체 파일을 복사합니다.

- **형식:** 로컬 폴더의 절대 경로를 담은 문자열.
- **조건:** 폴더가 존재하고 읽기 권한이 있어야 합니다.
- **관련 조건:** `destination`과 같거나 서로 포함하는 관계일 수 없습니다.

### destination

새 스냅샷 폴더들을 보관할 대상 폴더입니다. 실행마다 이 폴더 아래에 별도의 폴더가 추가됩니다.

- **형식:** 로컬 폴더의 절대 경로를 담은 문자열.
- **조건:** 폴더가 존재하고 쓰기 권한이 있어야 합니다.
- **관련 조건:** 이전 스냅샷은 자동 삭제되지 않으므로 저장 공간을 확인합니다.

---

## 사용 예시

```json
{
  "source": "C:/Work/notes",
  "destination": "D:/Backups/notes"
}
```

실행을 요청하면 `C:/Work/notes`의 파일을 `D:/Backups/notes` 아래 새 스냅샷 폴더에 복사하도록 지정한 설정입니다.

설명용 Windows 경로이며 두 폴더는 미리 준비해야 합니다. 이 가상 프로젝트는 실제 실행 프로그램을 제공하지 않습니다.
