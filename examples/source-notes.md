# 파일 백업 도구 — 예시용 공통 자료

세 완성 예시와 AI 초안 점검이 함께 사용하는 가상 프로젝트의 명세입니다.

- **가상 프로젝트:** 실제 배포된 프로그램이나 실행 가능한 제품이 아닙니다.
- **문서의 근거:** 예시에서 설명하는 동작과 설정은 이 자료에 한정합니다.
- **미정 사항:** 여기에 없는 기능과 동작은 추측하지 않고 확인 필요로 표시합니다.

## 목적과 범위

이 도구는 지정한 폴더의 현재 파일을 새 스냅샷 폴더로 복사합니다. 실행할 때마다 전체 파일을 복사하고, 이전 실행의 스냅샷은 수정하거나 자동으로 삭제하지 않습니다.

백업은 실행 시점의 사본을 따로 남기는 작업입니다. 이 자료에서 동기화는 현재 원본의 상태를 대상에 맞추는 방식으로 비교하며, 도구 자체에 동기화 기능은 없습니다.

---

## 구성요소와 동작

사용자가 작업 실행을 요청하면 다음 순서로 진행합니다. 실행 요청에 사용하는 실제 CLI 문법은 정하지 않았습니다.

1. **설정 읽기:** UTF-8 JSON 파일 `backup.json`을 읽습니다.
2. **입력 검사:** 설정값, 경로 관계, 원본 폴더 존재 여부와 접근 권한을 검사합니다. 실패하면 복사 전에 중단합니다.
3. **파일 복사:** 대상 폴더 아래에 실행별로 새 폴더를 만들고 원본 파일을 하위 폴더 구조와 함께 복사합니다.
4. **결과 보고:** 성공 여부와 성공적으로 복사한 파일 수를 보여줍니다. 로그 파일 형식과 저장 위치는 정하지 않았습니다.

복사 도중 오류가 나면 작업을 중단하고 실패를 보고합니다. 이미 복사한 파일이 있는 불완전한 폴더는 남으며, 완성된 스냅샷으로 취급하면 안 됩니다.

## 설정 명세

| 키 | 자료형 | 필수 여부 | 기본값 |
| --- | --- | --- | --- |
| `source` | 문자열 | 필수 | 없음 |
| `destination` | 문자열 | 필수 | 없음 |

`source`는 읽을 수 있는 기존 로컬 폴더의 절대 경로입니다. `destination`은 쓰기 가능한 기존 로컬 폴더의 절대 경로입니다.

두 경로는 같을 수 없으며, 어느 한쪽이 다른 쪽의 하위 폴더여도 안 됩니다. 경로 별칭과 심볼릭 링크에 대한 동작은 정의하지 않았습니다.

```json
{
  "source": "C:/Work/notes",
  "destination": "D:/Backups/notes"
}
```

이 예시는 Windows 경로로 설명하지만 실제 지원 운영체제 목록은 정하지 않았습니다. 폴더는 사용자가 미리 준비합니다.

## 제약과 미정 사항

전체 파일을 매번 복사하므로 실행 횟수와 원본 크기에 따라 저장 공간이 증가합니다. 작업 중 원본을 수정하면 하나의 일관된 시점이 보장되지 않으므로, 변경을 멈춘 뒤 실행합니다.

자동 일정, 증분 백업, 압축, 암호화, 자동 보존 기간 관리, 복원 명령은 예시 범위에 없습니다. 스냅샷 이름 규칙, CLI 문법, 종료 코드, 링크 처리, 손상 검증 방식은 미정입니다.
